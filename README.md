# Perspektíva

A **Perspektíva** egy olyan cikkgyűjtő platform, amely különböző médiumok tartalmait egyetlen, központi felületen teszi elérhetővé. Az oldal elsődleges célja az átláthatóság biztosítása és a hírekhez való könnyű hozzáférés megteremtése a mai információs zajban.

## Főbb funkciók
* **Aggregált tartalom:** Különböző források hírei egy helyen jelennek meg.
* **Intelligens szűrés:** A felhasználók egyszerűen válogathatnak az egyes médiumok és források között.
* **Rendszerezett áttekintés:** Átlátható felület, amely segíti a különböző nézőpontok megismerését.
